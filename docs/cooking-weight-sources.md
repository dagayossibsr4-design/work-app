# מקורות המרת משקל לפני ואחרי בישול

USDA ARS, Cooking Yields: https://www.ars.usda.gov/northeast-area/beltsville-md-bhnrc/beltsville-human-nutrition-research-center/methods-and-application-of-food-composition-laboratory/mafcl-site-pages/cooking-yields/

המקור מציין שתשואת בישול היא שינוי משקל הנובע מאובדן או ספיחת לחות ושומן במהלך הבישול, ומספק טבלאות תשואה לפי סוגי בשר ועוף ופרוטוקול בישול. לכן האפליקציה משתמשת במקדמי תשואה מפורשים לפי קבוצת מזון, ומציגה שההמרה היא אומדן שתלוי בשיטת הבישול.

הערה: עבור מזונות ללא מקור לפני/אחרי בישול מפורש במאגר, אין לבצע המרה אוטומטית; הממשק ישאיר את מצב השקילה הקיים ויציג את הערכים לפי הרשומה הזמינה.
